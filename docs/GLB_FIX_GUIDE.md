# خطوات إلزامية: تقليل مثلثات نموذجي GLB الضخمين

## التشخيص المؤكد
| الملف | المثلثات | الحجم |
|---|---|---|
| plant-cell-first001.glb | ~1,943,000 | 57 MB |
| white-blood-cell-user.glb | ~1,893,000 | 54 MB |

الحجم الطبيعي لنموذج ويب/موبايل حي: **10,000 – 100,000 مثلث**. أنتما حاليًا أعلى بـ 20-190 ضعفًا من الحد الأعلى المعقول. هذا لا يُصلح بالكود — يحتاج تبسيط الشبكة الهندسية (mesh decimation) فعليًا.

---

## الطريقة الأسهل: Blender (مجاني)

1. حمّل Blender من blender.org وثبّته.
2. افتح Blender → File → Import → glTF 2.0 → اختر `plant-cell-first001.glb`.
3. حدد الجسم (Object) → اذهب لتبويب **Modifiers** (أيقونة المفتاح الإنجليزي) → أضف **Decimate**.
4. اختر النوع **Collapse**، واضبط **Ratio** تدريجيًا (جرّب 0.02 أولًا = تبسيط لـ 2% من المثلثات الأصلية، أي حوالي 38,000 مثلث).
5. راقب الشكل في العرض ثلاثي الأبعاد — إذا فقد تفاصيل مهمة، ارفع النسبة قليلًا (0.03 - 0.05).
6. طبّق المعدّل (Apply)، ثم: File → Export → glTF 2.0 (.glb).
7. كرر بالضبط لملف `white-blood-cell-user.glb`.

**نتيجة متوقعة:** كل ملف ينخفض من ~55 ميجابايت إلى **1-3 ميجابايت** تقريبًا، بدون فقدان يُذكر في المظهر على شاشة موبايل.

---

## بعد التبسيط: اضغط بـ gltf-transform (خطوة إضافية موصى بها)

على جهازك (يحتاج اتصال إنترنت لمرة واحدة):
```bash
npm install -g @gltf-transform/cli
gltf-transform draco plant-cell-decimated.glb plant-cell-final.glb
gltf-transform draco white-blood-decimated.glb white-blood-final.glb
```
هذا يضغط البيانات المتبقية أكثر (ضغط Draco) — الكود عندك في `AssetCellModel` بالفعل يدعم فك ضغط Draco تلقائيًا (`useGLTF(url, true, true)`)، فلا حاجة لتعديل أي كود إضافي.

## استبدال الملفات
ضع الملفات النهائية بنفس الأسماء في `public/models/` (استبدال المباشر)، لا حاجة لتغيير أي مسار في `cells.ts`.
